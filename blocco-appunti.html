Blocco Appunti

Collega GitHub (configurazione iniziale)

Da fare una sola volta. Gli appunti verranno salvati in un file dentro un tuo repository privato e sincronizzati tra tutti i dispositivi.

  1. Su GitHub crea un repository privato (es. blocco-appunti). Può essere vuoto.
  2. Crea un token personale "fine-grained": Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  3. In Repository access scegli Only select repositories e seleziona quel repo. In Permissions → Repository permissions → Contents imposta Read and write. Genera e copia il token.
  4. Incolla qui sotto il token e il nome del repository, poi Salva e connetti.

Il token resta salvato solo in questo browser/dispositivo (non viene inviato a nessuno tranne GitHub). Usa un token limitato a questo solo repository, con permesso solo su Contents.
