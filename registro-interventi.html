Connetti a GitHub

Le segnalazioni vengono salvate in un file interventi.json nel tuo repository privato.

Setup (una volta sola):
  1. Crea un repository privato su GitHub (anche vuoto).
  2. Crea un token fine-grained: Settings → Developer settings → Personal access tokens → Fine-grained tokens.
  3. In Repository access scegli Only select repositories → quel repo. In Permissions → Repository → Contents metti Read and write. Genera e copia il token.
  4. Incolla qui sotto e premi Connetti.
Il token resta solo in questo browser e viene inviato solo a GitHub.
